A production-ready, interactive personal portfolio website themed as an **"Antigravity Newspaper Rack"** for **Mihir Pratap Singh** (Full-Stack Web Developer & Software Engineer). 

The portfolio blends 1920s vintage broadsheet editorial aesthetics with fluid 60fps zero-gravity 3D physics, procedural Web Audio sound synthesis, shared-element zoom transitions, and responsive fallback modes.

---

## 🌟 Key Features

### 1. 3D Antigravity Physics Engine (Zero-Gravity Broadsheet Rack)
- **Harmonic Zero-Gravity Drift**: Simulates 4 floating vintage newspaper broadsheets drifting with pitch, roll, and yaw.
- **Inter-Paper Repulsion**: Proximity physics prevent cards from overlapping or clipping.
- **Aerodynamic Cursor Disturbance**: Moving the cursor across the airfield exerts a natural air-drift that pushes nearby papers away.
- **Tactile Drag & Flick**: Click and drag any broadsheet to toss it across the zero-gravity viewport with realistic momentum and air friction damping.
- **Hover Depth**: Brings active papers forward on the Z-axis with scaling and deepened drop shadows.

### 2. Four Authentic Broadsheet Editions
- **Edition I: "THE DISPATCH" (Executive Overview)**: High-level summary of software engineering philosophy, core achievements, and directory index.
- **Edition II: "THE BIOGRAPHY" (Profile & About Me)**: Mihir's portrait photo treated with vintage newsprint halftone and sepia filters, B.Tech CSE (8.0 CGPA) at Babu Banarasi Das University, 1st prize hackathon victory (F.I.F.T), 50+ LeetCode solved, and categorized technical skills.
- **Edition III: "THE GAZETTE" (Selected Works)**: Production full-stack case studies:
  - *Full-Stack Task Manager with Analytics Dashboard* (React, Node, Express, MySQL, Chart.js, JWT)
  - *EcoPulse — Carbon Footprint Monitoring Platform* (React, Node, Express, REST APIs, Unit Testing)
- **Edition IV: "THE CLASSIFIEDS" (Contact & Communication)**: Working vintage telegram form with live typing character counter, procedural Morse key sounds, direct telephone (+91-9643476007), email (mihirprsingh@gmail.com), LinkedIn, GitHub, and Resume PDF download action.

### 3. Procedural Web Audio API (Zero External Assets)
- Built without external audio files:
  - **Paper Rustle**: Bandpass-filtered white noise buffer with ADSR envelope.
  - **Airy Whoosh**: Sweeping filter oscillators on page tosses and unroll transitions.
  - **Morse Key Pips**: Auditory feedback when typing in the telegram contact form.
  - **Accessible Audio Toggle**: Muted by default (`AUDIO: MUTED`) with keyboard shortcut `M`.

### 4. Accessibility & Responsive Systems
- **Accessible Index Drawer**: Top bar archives drawer providing immediate keyboard and screen-reader access to all editions.
- **Static Grid Mode**: Respects `prefers-reduced-motion` and provides a manual toggle to switch from 3D physics to a responsive 4-column broadsheet grid.
- **Keyboard Shortcuts**: `Tab` through cards, `Enter`/`Space` to unroll, `ESC` to fold paper back to rack, `M` to toggle sound.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Framer Motion, Lucide React
- **Physics**: Custom 60fps Verlet / Harmonic 3D Physics Engine with Proximity Repulsion
- **Audio**: Web Audio API (Procedural Noise Synthesis)
- **Build Tool**: Vite 5
- **Typography**: Playfair Display, Cinzel, Merriweather, JetBrains Mono

## 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/mihirsingh01/mihir_portfolio.git

# Navigate to project directory
cd mihir_portfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
